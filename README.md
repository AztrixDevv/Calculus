# Cálculo sem mistério

Guia interativo e intuitivo de **Cálculo 1**: limites, continuidade, derivadas, aplicações, integrais e o Teorema Fundamental do Cálculo, com exercícios explicados e feedback imediato.

## Conteúdo

- Trilha de aprendizagem em três perguntas: para onde está indo, quão rápido muda e quanto se acumulou
- Seis aulas com fórmulas, exemplos e resumos de regras
- Quiz com filtro por assunto, dicas e contagem de acertos
- Interface neumórfica com menu lateral recolhível e animações (GSAP)
- Responsivo e com suporte a `prefers-reduced-motion`

## Como usar

É um site estático de um único arquivo. Basta abrir o `index.html` no navegador.

> As animações usam GSAP carregado por CDN (cdnjs). Sem internet, a página funciona normalmente, apenas sem as animações.
