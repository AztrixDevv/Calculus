01 · Aproximar sem necessariamente chegar

Limites

Imagine caminhar até uma parede percorrendo, a cada passo, metade da distância restante. Você se aproxima cada vez mais. O limite descreve para onde a função tende quando x se aproxima de um ponto.

limx→a f(x) = L Quando x se aproxima de a, f(x) se aproxima de L.

Tente substituir x por a. Se aparecer 0/0, simplifique (por exemplo, fatorando) antes de substituir. O valor da função exatamente em a pode ser diferente ou nem existir.

Exemplo: (x² − 4)/(x − 2) = x + 2, para x ≠ 2. Quando x → 2, o limite é 4, embora a fração original não esteja definida em 2.
Limites laterais

O limite bilateral existe quando os limites pela esquerda e pela direita existem e são iguais.

Limites no infinito

Descrevem o comportamento distante da função e podem revelar uma assíntota horizontal.

Se o denominador tende a zero e o numerador não, examine os sinais de cada lado: o limite pode divergir para +∞ ou −∞.

A ponte entre limites e funções

Continuidade

Intuitivamente, uma função é contínua em a quando o gráfico não tem salto, buraco ou ruptura naquele ponto. Para isso, f(a) deve existir, o limite deve existir e eles precisam ser iguais:

limx→a f(x) = f(a)

Polinômios são contínuos em toda parte; funções racionais, onde o denominador não zera. O Teorema do Valor Intermediário garante que uma função contínua que muda de sinal num intervalo cruza zero em algum ponto desse intervalo.

02 · A taxa de mudança

Derivadas

A velocidade média é a variação da posição dividida pelo tempo. Para obter a velocidade em um instante, aproxime os dois instantes até coincidirem: surge um limite, que define a derivada.

f′(a) = limh→0 [f(a+h) − f(a)] / h Geometricamente, f′(a) é a inclinação da reta tangente ao gráfico.
Regras básicas

(xⁿ)′ = n·xⁿ⁻¹
(cf)′ = cf′
(f ± g)′ = f′ ± g′

Produto, quociente e cadeia

(fg)′ = f′g + fg′
(f/g)′ = (f′g − fg′)/g²
(f(g(x)))′ = f′(g(x))g′(x)

Exponenciais e logaritmos

(eˣ)′ = eˣ
(aˣ)′ = aˣ ln a
(ln x)′ = 1/x, x > 0

Trigonométricas

(sen x)′ = cos x
(cos x)′ = −sen x
(tg x)′ = sec²x

Exemplo: se f(x) = x³, então f′(x) = 3x². Em x = 2, a inclinação é 12. Se s(t) é posição, s′(t) é velocidade e s″(t), aceleração.

Na derivação implícita, derive ambos os lados em relação a x. Como y depende de x, a regra da cadeia dá (y²)′ = 2y·dy/dx.

Lendo o comportamento de uma função

Aplicações das derivadas

Crescimento e extremos

f′ > 0 indica crescimento; f′ < 0, decrescimento. Pontos onde f′ = 0 ou não existe são candidatos a máximos e mínimos locais.

Concavidade

f″ > 0 indica concavidade para cima; f″ < 0, para baixo. Uma mudança pode indicar ponto de inflexão.

Otimização

Modele a situação com uma função, encontre pontos críticos e compare valores pertinentes, incluindo extremos do intervalo.

Aproximação linear

Perto de a, f(x) ≈ f(a) + f′(a)(x − a): a curva se parece com sua reta tangente.

03 · Somar para medir o todo

Integrais

Para estimar a área sob uma curva, divida a região em retângulos estreitos e some suas áreas. No limite de retângulos cada vez menores, obtemos a integral definida.

∫ab f(x) dx = lim Σ f(xᵢ*) Δx Acumulação líquida: acima do eixo x conta positivo; abaixo, negativo.

Uma integral indefinida encontra uma primitiva F, cuja derivada é f. Como a derivada de uma constante é zero, escrevemos + C.

Primitivas essenciais

∫xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ −1
∫1/x dx = ln|x| + C
∫eˣ dx = eˣ + C
∫cos x dx = sen x + C

Técnicas

Substituição: u = g(x), útil quando aparece g e sua derivada (regra da cadeia ao contrário).
Por partes: ∫u dv = uv − ∫v du, útil em produtos.

O elo entre as duas grandes ideias

Teorema Fundamental do Cálculo

Derivar e integrar são operações inversas. Se F′ = f, a área líquida entre a e b pode ser calculada pela diferença dos valores da primitiva:

∫ab f(x) dx = F(b) − F(a)

Além disso, se A(x) = ∫ax f(t)dt, então A′(x) = f(x): a taxa de crescimento do acumulado é o próprio valor que está sendo acumulado.

Exemplo: ∫₀² 3x² dx = [x³]₀² = 8.
